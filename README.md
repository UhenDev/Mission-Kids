## 🌟 1. Tentang MISSION KIDS

**MISSION KIDS** adalah platform edukasi interaktif berbasis misi yang dirancang khusus untuk siswa Sekolah Dasar (SD, usia 7–12 tahun). 

Berbeda dengan sistem e-learning (LMS) konvensional yang membosankan dengan kuis pilihan ganda teks kering, atau aplikasi game murni yang minim esensi belajar, **MISSION KIDS** menempatkan anak sebagai penjelajah dan pemecah masalah (*active problem solver*).

### 💡 Konsep Utama:
> **"Anak belajar dengan menghadapi sebuah misi atau masalah nyata, mengeksplorasi informasi pendukung, melakukan aktivitas interaktif melalui manipulasi objek visual, memecahkan tantangan sebab-akibat, mendapatkan feedback yang membangun, dan merefleksikan makna pembelajaran."**

## 🤖 2. Sahabat AI MIKO (Scaffolding, Bukan Pemberi Jawaban)

Didampingi oleh **MIKO** (*Mindful Interactive Knowledge Operator*), sebuah kecerdasan buatan sosial-kognitif yang dirancang dengan etika pedagogis ketat:

- ❌ **Bukan Chatbot Terbuka:** Tidak ada interaksi chat teks bebas tanpa pengawasan yang berisiko bagi anak.
- ❌ **Bukan Mesin Pembocor Jawaban:** MIKO menolak memberikan jawaban instan demi menjaga daya nalar dan ketahanan berpikir (*grit*) anak.
- ✅ **Bantuan Bertahap (3-Tier Scaffolding):**
  1. **Level 1 (Konseptual):** Mengajukan pertanyaan reflektif yang memicu rasa ingin tahu anak.
  2. **Level 2 (Spesifik):** Mengarahkan fokus perhatian anak ke variabel atau tombol manipulasi kunci.
  3. **Level 3 (Aksi Terbimbing):** Memberikan instruksi aksi bertahap agar anak dapat menuntaskan misi secara mandiri.
- 🛡️ **Zero Single-Point-of-Failure:** Jika koneksi API AI eksternal offline atau kuota habis, MIKO 100% otomatis beralih ke petunjuk deterministik pedagogis bawaan tanpa gangguan pada pengalaman belajar anak.

## 🏆 4. Sistem Gamifikasi Positif (*Playful Precision*)

- **⭐ Rating Bintang (1–3 Bintang):** Dihitung berdasarkan kemandirian anak menyelesaikan misi (3 bintang untuk pemecahan tanpa petunjuk berlebih).
- **📈 Progres Level Petualang:** 5 tingkatan level dari *Penjelajah Pemula (Lvl 1)* hingga *Master Explorer (Lvl 5)*.
- **🏅 Medali Kehormatan (Achievements):** Dibuka secara otomatis berdasarkan pencapaian dunia dan ketekunan belajar.
- **🔊 Sintesis Audio Web Audio API:** Efek suara pop gelembung, nada kemenangan arpeggio, dan denting bintang tanpa aset MP3 eksternal (100% ringan, instan dimuat, dan dilengkapi tombol bisu).
- **🎊 Ledakan Konfeti Kanvas HTML5:** Rayakan setiap keberhasilan anak dengan semburan konfeti kanvas dinamis.

## 🔒 5. Keamanan & Standar Privasi Anak (COPPA & GDPR-K)

1. **Zero PII (Personally Identifiable Information):** Tidak meminta nama lengkap, email, nomor handphone, lokasi GPS, maupun data sekolah. Pendaftaran hanya memerlukan nama panggilan, karakter avatar, username, dan password sederhana.
2. **Perlindungan Injeksi SQL:** 100% kueri database menggunakan PDO Prepared Statements dengan parameter binding.
3. **Pencegahan XSS:** Seluruh output data disaring melalui fungsi pengaman `htmlspecialchars()`.
4. **Proteksi CSRF:** Token kriptografis acak `bin2hex(random_bytes(32))` divalidasi pada seluruh permintaan formulir.
5. **Keamanan Sesi Ketat:** Cookie dilindungi dengan bendera `HttpOnly`, `SameSite=Lax`, `use_strict_mode=1`, dan regenerasi ID sesi otomatis.

## 🛠️ 6. Teknologi & Arsitektur Sistem

- **Backend:** PHP 8.2+ Native (Arsitektur MVC Modular tanpa framework bloated).
- **Database Engine:** MySQL / MariaDB dengan fallback otomatis ke SQLite lokal berkinerja tinggi.
- **Frontend:** Semantic HTML5, Vanilla CSS3 (Custom Design System ramah anak), Modern Vanilla JavaScript (ES6+).
- **Zero Build Step:** Tidak memerlukan kompilasi Node.js atau Webpack, siap dijalankan langsung di server apa pun.

### Struktur Direktori:
```text
mission-kids/
├── config/              # Konfigurasi aplikasi & factory database
├── database/            # Skema SQL, seeder data 9 misi & medali
├── docs/                # 10 Dokumen spesifikasi teknis lengkap
├── public/              # Web Root (index.php, CSS, JS engine)
│   ├── css/             # Design system, animasi, dunia & misi
│   └── js/              # Engine misi, MIKO AI client, Web Audio, Canvas
├── src/                 # Backend MVC
│   ├── Controllers/     # Auth, Home, Mission, dan JSON API
│   ├── Helpers/         # Session & Security (CSRF, XSS)
│   └── Services/        # AuthService, Gamification, MissionProgress, MikoAi
└── templates/           # View layout & halaman antarmuka siswa
```

## 🚀 7. Panduan Menjalankan Secara Lokal

### Prasyarat:
- PHP 8.2 atau lebih baru.
- Ekstensi PHP yang aktif: `pdo`, `pdo_mysql`, `pdo_sqlite`, `curl`.
- MySQL / MariaDB (Opsional, SQLite sudah otomatis aktif sebagai fallback).

### Langkah Menjalankan:
1. **Salin / Masuk ke direktori project:**
   ```bash
   cd mission-kids
   ```

2. **Migrasi & Isi Data Misi (Seeding):**
   ```bash
   php database/migrate.php
   ```

3. **Jalankan Server Lokal:**
   ```bash
   php -S 127.0.0.1:8080 -t public
   ```

4. **Buka di Peramban Web:**
   Akses `http://127.0.0.1:8080` melalui browser pilihan Anda.

## 🌐 9. Panduan Deployment Produksi

### Opsi A: Shared Hosting / cPanel (Direkomendasikan)
1. Unggah seluruh isi folder project ke hosting Anda.
2. Atur Document Root domain / subdomain mengarah ke folder `/public`.
3. Buat database MySQL di cPanel, salin `.env.example` menjadi `.env`, lalu isi kredensial database.
4. Jalankan script migrasi sekali via terminal SSH (`php database/migrate.php`) atau import file [`database/schema.sql`](database/schema.sql) melalui phpMyAdmin.

### Opsi B: Virtual Private Server (VPS Linux Ubuntu/Debian)
1. Pasang Nginx/Apache dan PHP 8.2-FPM (`apt install php8.2-fpm php8.2-mysql php8.2-curl php8.2-sqlite3`).
2. Arahkan root web server ke `/var/www/mission-kids/public`.
3. Aktifkan sertifikat SSL gratis via Let's Encrypt (`certbot --nginx`).
